## 2. Image Build Verification Protocols

### 2.1 API Service Verification
- **Command:** `docker build -f docker/Dockerfile.api -t praxis-api:test --target production .`
- **Startup Invariant:** Container starts within 5 seconds and returns HTTP 200 on `/health`.
- **Smoke Route:** `GET /health` returns JSON `{"status": "ok", "version": "...", "timestamp": "..."}`.
- **Signal Handling:** Responds to `SIGTERM` within 30 seconds with clean connection draining.

### 2.2 Realtime Service Verification
- **Command:** `docker build -f docker/Dockerfile.realtime -t praxis-realtime:test --target production .`
- **Baked Assets:** Whisper `small` int8 model directory exists at `/app/.cache/huggingface` and Silero VAD ONNX model is pre-cached.
- **Startup Invariant:** Offline hub enforcement (`HF_HUB_OFFLINE=1`) prevents network requests during model loading.
- **WebSocket Handshake:** WebSocket listener accepts connection upgrade on `/ws/sessions/{id}` with 18-byte binary frame header.

### 2.3 ARQ Worker Verification
- **Command:** `docker build -f docker/Dockerfile.worker -t praxis-worker:test --target production .`
- **Startup Invariant:** Initializes ARQ worker settings and binds HTTP health probe on port 8080.
- **Graceful Termination:** Finishes current job execution when receiving `SIGTERM` before process exit.

### 2.4 Sandbox Service Verification
- **Command:** `docker build -f docker/Dockerfile.sandbox -t praxis-sandbox:test --target production .`
- **Isolation Checks:**
  - Non-root execution verified (`whoami` -> `sandbox`).
  - Read-only root filesystem with ephemeral `/tmp`.
  - Network egress disabled (`--network none` in execution run).

## 3. Supply-Chain & Immutability Rules

1. **Tagging Policy:** Release containers are tagged **strictly by immutable git commit SHA** (`${SHORT_SHA}`). The mutable `:latest` tag is prohibited in release deployments.
2. **Digest Enforcement:** Deployments to Cloud Run capture and pin the cryptographic image digest (`sha256:...`) from Artifact Registry.
3. **Lockfile Hashes:** All Python wheels are validated against sha256 hashes generated by `pip-compile --generate-hashes`.
